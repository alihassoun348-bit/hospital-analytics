

A Python-based health data management and analytics application built to streamline patient record processing, discharge tracking, and operational reporting.

- *Data Ingestion & Management:* Loads patient records efficiently via pandas and provides functions to append new patient data.
- *Status Tracking:* Features logic to locate specific patients by ID and update discharge statuses to Recovered.
- *Operational Analytics:* Generates automated reports including:
  - Patient volume breakdown by department.
  - Average length of stay (days) calculations.
  - Primary diagnosis frequency analysis.

- *Language:* Python
- *Data Processing:* Pandas, NumPy
- *Data Visualization:* Matplotlib, Seaborn
